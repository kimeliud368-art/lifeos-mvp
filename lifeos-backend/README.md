# LifeOS AI — MVP Backend

FastAPI backend covering: auth, tasks, notes, and AI chat with long-term memory (Claude-powered).

## 1. Prerequisites

- Python 3.10+
- PostgreSQL installed and running locally
- An Anthropic API key (from console.anthropic.com)

## 2. Setup

```bash
# From inside this lifeos-backend folder:

# Create and activate a virtual environment
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Create your .env file
cp .env.example .env
# then open .env and fill in DATABASE_URL, SECRET_KEY, ANTHROPIC_API_KEY
```

## 3. Create the database

```bash
# Using the psql CLI (adjust user if needed):
createdb lifeos
```

## 4. Run the server

```bash
uvicorn app.main:app --reload
```

The API will be live at `http://127.0.0.1:8000`.
Interactive docs (auto-generated by FastAPI) at `http://127.0.0.1:8000/docs` — use this to test every endpoint before the Flutter app is ready.

## 5. Quick test flow (via /docs or curl)

1. `POST /auth/signup` — create a user (email, password)
2. `POST /auth/login` — get back an access_token
3. Click "Authorize" in `/docs` (or send `Authorization: Bearer <token>` header) using that token
4. `POST /chat/` with `{"message": "I'm trying to lose 8kg, can you remind me to drink water?"}`
   - Should create a task via tool use and store a memory fact
5. `GET /chat/memory` — confirm the fact got stored
6. Send another chat message days later (or right now) referencing something related — the AI should use that stored memory in its reply

## Notes

- Tables are auto-created on first run (`Base.metadata.create_all`). This is fine for MVP; switch to Alembic migrations once the schema stabilizes.
- CORS is wide open (`allow_origins=["*"]`) for local development — restrict this before any real deployment.
- The AI model is currently hardcoded to `claude-sonnet-4-6` in `app/routers/chat.py` — change there if needed.
